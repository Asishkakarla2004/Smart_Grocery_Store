# kOps prerequisites
Use an existing validated cluster; application CI must not provision a new cluster. Check `kops validate cluster`, `kubectl get nodes -o wide`, `kubectl top nodes`, `kubectl get pods -A`, `kubectl get storageclass`. Verify Calico or another policy-enforcing CNI, AWS EBS CSI (`kubectl get pods -n kube-system | grep ebs-csi`), and metrics-server (`kubectl top nodes`). Install an Ingress controller such as ingress-nginx, point DNS to its external address, and provision TLS (for example cert-manager) before applying the Ingress. EBS CSI StorageClass requires IAM permissions and driver installation. Do not commit kubeconfig, AWS credentials, kOps state store or private keys.
